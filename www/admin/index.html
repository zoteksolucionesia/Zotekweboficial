ℹ️ ¿Cómo funciona?

1

Follow-up de Leads Fríos

Se ejecuta cada hora para detectar leads que no han respondido en 24/48/72 horas. Envía emails automáticos de seguimiento para recuperar ventas perdidas.

2

Recordatorio de Citas

Se ejecuta todos los días a las 10 AM para enviar recordatorios de citas del día siguiente. Reduce los no-shows en 60% y mejora la experiencia del cliente.

3

Configuración en Cloud Scheduler

Las automatizaciones se ejecutan en Google Cloud Scheduler. Puedes configurar horarios, ver logs y ejecutar manualmente desde la consola. Abrir Cloud Scheduler →
